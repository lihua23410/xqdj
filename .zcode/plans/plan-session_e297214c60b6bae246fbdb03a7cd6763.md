# 新战斗机「静电魔球」实施计划

## 概述

给 xqdj 新增第 46 只战斗机 **静电魔球**（目录 `character/static/`，Kind `"静电魔球"`）：摩擦起电、满电后在敌人之间放链式闪电的爆发型战斗机。**纯用现有 `internal/unit` API 实现，不改 `internal/sim`、不改 `main.go`、不改前端框架代码。**

## 机制设计

**定位**：中距离自动爆发。核心资源是「电荷」0–100。

| 机制 | 数值/规则 |
|---|---|
| 被动·摩擦起电 | 移动中 +4/秒；发生物理碰撞 +6；自己被确认受伤 +5；上限 100。站定不充能（摩擦梗） |
| 技能·放电（满电自动） | 闪电链最多命中敌人 **4 跳**，伤害逐跳衰减 **10→7→5→4**；每跳从当前节点出发选射程 220 内最近的 `Hittable` 敌方单位（战斗机或活随从）；**链弹不到敌人时把自己当作最低优先级弹射节点**（不出伤，仅中继），于是 1v1 也能完整倾泻 4 跳：敌→己→敌→己→敌…。放电后电荷清零 |
| 满电追击 | 电荷满但敌人不在射程内：临时 `SetCruise` +30 逼近，敌人看得见它「发光变亮」（皮肤随电荷变亮 + 自身挂「静电充能」StackMark 作为可见预警） |
| 技能·磁吸（CD 6s） | 电荷 ≥55 时把 240 内最近敌人用 `AddFS` 拉向自己 0.35 秒（约 150 速率），凑放电走位。`AddFS` 拉人 / 对他人眩晕在现有角色（血契、pink）中均有先例 |

**AI 行为（角色是自主 Actor）**：平时游走攒电荷、蹭碰撞；≥55 用磁吸拖人；满电追击进入射程后瞬间结算整条链（同一 tick 内对所有跳点发 `Damage`，全部走 `unit.Hittable` 过滤，不漏活随从；同槽友军永远不会被链到）。

**技术要点**：
- 选链逻辑写成纯函数（输入快照列表+当前节点+上跳节点，输出下一跳），配套包内 `_test.go` 单测，重点覆盖 1v1 自中继、多敌人分散、排除上一节点。随机一律 `unit.NewRNG(ctx.Stream)`，不碰全局 rand（bug.md 里谭泳辰的种子教训）。
- 电荷用对自己 `StackMark{Kind:"静电充能"}` 记账，Snapshot.Marks 对敌可见 → 天然的对手预警 + 皮肤 JS 读 mark 数控制发光强度。
- 闪电特效沿用谭泳辰先例：`FX{Name, X, Y, VX, VY, Slot}` 编码线段起点→终点，Slot 作段序号供前端错峰播放；一次性特效走 `arena.registerShot`。

## 文件清单

**新增**
- `character/static/静电魔球.go` — 注册（`unit.Spec{Radius:15, MaxHP:90, Speed:160, Vision:240, Fighter:true}`）+ 电荷管理 + 放电/磁吸/追击 AI（约 400 行，中文包名，风格对齐现有角色）

**修改**
- `character/all.go` — 跑 `go generate ./character` 自动再生成
- `战斗机.md` — 按名册格式补「静电魔球」条目（外观/特性/五维雷达）

## 验证步骤

1. `go generate ./character` 后 `go test ./...` 全绿
2. `go run ./cmd/winrate -only "静电魔球" -n 30` 跑对全部 45 只的胜率冒烟：若整体 <25% 或 >75% 就调电荷速率/伤害表再跑
3. 起 `go run .`，用浏览器开一局「静电魔球 vs 靶子」确认皮肤注入、闪电弧线渲染正常
