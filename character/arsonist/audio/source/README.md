# 原始火焰录音

这些文件从仓库原有 `tmp/fire-sfx/2026-10-27/` 缓存原样复制到这里，以使音效生成脚本在新检出中仍可运行，不依赖临时目录。

- `fire-catch.wav`：原缓存 `fire-catch-ignition-01.wav`，themightyglider / Catching fire，https://opengameart.org/content/catching-fire ，CC0；原缓存从 `flame.ogg` 转码。
- `fire-crackle.wav`：原缓存 `fire-crackle-short-01.wav`，AntumDeluge / Fire Crackling，https://opengameart.org/content/fire-crackling ，CC0。

许可文本随最终资源保存在 `../../fx/LICENSE-CC0-1.0.txt`，处理与署名说明见 `../../fx/README.md`。本目录不被 `go:embed fx` 打包，运行时只加载处理后的资源。
