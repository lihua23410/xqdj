# 普通分身者外观

灰蓝色低光泽核心带明暗折面与双片裂隙，本体和三只分身同形。分身半透明，两层错位描边表现折射；首次出现时用 0.28 秒收拢轮廓。只给本体显示公共生命数字，分身没有独立生命读数。

已有 `swap` 事件驱动两处身体各 0.36 秒的轮廓错位，并在两个原始换位点播放 0.42 秒的裂片展开、断环扩散与亮裂隙收束，保留公共换位闪光；不增加长连线、常驻残影或全屏粒子。裂片留在事件发生的位置，机体继续移动时仍能看清交换的两处。状态存放在各自导引节点，随单位消失清理，时间回退时重置。开局、换位和环上流光按比赛时间推进，暂停冻结、导出复现；非因果借用皮肤时只借静态轮廓，不创建分身演出的状态。

分身的完整攻击细环保留，三处浅色流光缓慢沿环移动。弧实际碰到可伤害目标时额外发出私有 `doppel-touch` 事件，在目标接触面显示短促小闪光，无新增音频。只增加视觉事件，伤害、冷却、生成与换位结算保持原样。图形均为包内 CSS/SVG，不使用外部图片或字体。
