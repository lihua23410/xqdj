# 内燃机(泵之心)

所有战斗逻辑、零件、场地几何和外观都位于本角色包。`character/all.go` 仅由原有生成器更新注册导入；引擎与通用前端没有改动。

外观为黑铁装甲的蒸汽机械心脏：不对称的器官轮廓、铆接板与黄铜包边，胸口嵌一枚黄铜包边的观察窗，窗内炉火随搏动明灭。粗黄铜管以直角弯头从左上肩进入、绕左肋至底缘，再从右侧接回齿轮组；顶部另有粗烟囱与阀门，压力表固定在左胸。整体保持刚性，搏动由观察窗火光、压力表指针、齿轮、阀门手轮与蒸汽呈现，收缩时排出少量蒸汽。

球皮依据用户的 `hero-bright.png` 概念草图优化：黑铁厚壁炉壳打底，粗大黄铜直角主管与块状接头绕过炉窗，顶部烟囱、左胸压力表和下部齿轮保持原来的识别点。横竖管道各有圆柱高光，管接头、紧固件与黑铁骨架使用统一材质；本体保持刚性，炉火、压力表、齿轮、阀门和排汽表现搏动。

实战绘制尺寸在初版基础上放大约 50%，裸机即可清晰分辨炉窗、压力表、粗管与传动机构；所有固定安装的零件使用相同比例。角色自己的生命数字上移，避免压住顶部管组。此调整只影响外观，碰撞和战斗数值不变。

机械搏动采用自上而下传播的刚性机段行程：顶部管组下压 → 胸段炉心压合 → 下部传动座上收 → 尾段喷口回缩，短暂保压后复位。黑铁外壳划分为沿背脊滑轨运动的三段，主管在套筒处滑合，各零件随其固定安装机段运动；护架作为固定承力框架。没有对整颗心做橡胶式缩放。动作来自模拟的搏动相位，暂停会冻结，眩晕时复位，双联阀带来第二次较弱机械收缩。

各零件逐一对应实际机械部位：左泵缸、右肩压力桥、右下传动轴、正时脊、燃烧室、护架、进气、涡轮、压力腔、排气、绞盘，以及炉窗光路、撞架、蒸汽缸和发电线圈。每件都有固定位置和完整的承力、管路连接；部分升级直接取代裸机小构件，掉落时恢复。拾取顺序与零件类别只影响掉落栈，不影响安装位置，不再添加通用圆周外挂。外观体积不改变碰撞；技能变化由零件行为决定。

外观预览：启动项目后访问 `/ball/内燃机(泵之心)/fx/preview.html`，可同等比例对比裸机、单件与满配，查看全部独立模块、切换满配组合并暂停搏动。预览复用对战的实际渲染函数。

- 零件目录：`parts/`，15 种各自独立子包。每次上场随机抽五种且不重复，保证其中至少有一个额外攻击组件；其余种类本局不上场。裸心开局，普通零件拾取后压到栈顶，武器组件拾取后自动插入栈底；受击始终弹出栈顶。后捡的武器插在更底层，停稳复捡也按同一规则入栈。武器类别与保底抽取共用 Weapon 登记，当前为激光、撞角、蒸汽缸与电弧线圈。
- 裸心：半径 18、生命 100、巡航 150；基础搏动 1 秒一轮，前 40% 舒张，收缩造成 3 点范围伤害并排开敌人，同时短促冲出。
- 每次主搏动收缩有 33% 概率将这次冲刺改为朝向最近的未安装、已停稳零件，随后巡航也转向该零件。没有可拾取零件则沿用原来的行动，不追加判断；弱回声不重复触发。概率按本角色随机流与搏动序号确定，不因感知频率或其他角色行动重抽。此时优先拾取转向，换向喷口不再偏转这次冲刺，撞角保留蓄能到后续收缩再冲敌人；受击击退期间仍遵守原来的不主动冲刺规则。零件本身不因本体转向而移动。
- 未拾取零件固定在场地原位，每次舒张仅在原位 0.35 范围内轻微抖动，不持续追随本体。绞盘只牵回曾经被打落且已经停稳的零件。
- 掉件阈值：累计 12 点可观测净掉血。护盾、格挡和免疫不算；空栈不记欠账。飞散初速 520、匀减速 650，0.8 秒后精确停稳，遇墙反弹。
- 夹板为 108 度弧形钢板，内外半径 25/31，12 秒绕一圈，不出伤。角色包用已知攻击快照做弧形扫掠拦截，并对可识别的来袭伤害报价作方向校验；范围伤害不会因持有夹板免疫。
- 攻击特效由每次收缩事件触发：在出招位置产生亮铜色双层压力波、外散火星和核心闪光，波纹不跟随之后移动的本体。场景画布取消通用引导线的居中变换，所有零件与特效按本场外轮廓裁切。
- 掉件起点先约束在合法场地内，后续飞散按小步检测墙与场边，零件不会越过场边。

新增四种事件驱动的攻击零件：

- 蓄压光棱镜是远距定向持续武器：两次主收缩蓄压，寻找中心距离至少 90、能触及 360 射程的可见敌人，没有远距机会时保留压力。先预警 0.28 秒并锁死射线方向，再持续灼烧 0.6 秒，每隔至少 0.12 秒按当前站位结算 1.6 伤害，完整停留约五次暴露。敌人可在预警时横移，也可中途离开或进入射线；它不会追踪目标转弯。本体可滑移，发射口随本体移动而角度保持锁定。贯穿沿线目标，遇实墙或场边截止，眩晕与掉件立即中断。弱回声不充能。
- 破阵撞角：每三次主收缩锁定 240 范围内敌人的方向，替换当次普通短冲为 0.26 秒定向冲撞；实际行进路径上的敌人每次只受 8 伤害并被撞开。撞墙、眩晕、掉件取消冲撞。
- 蒸汽泄压缸：每次主收缩在出招位置留下半径 82 的蒸汽云，持续 0.36 秒，分三次各造成 1.5 伤害，并施加短促减速。云不跟随本体，不能穿实墙命中。
- 接触电弧线圈是近身碰撞反击武器：仅在 90 范围内有敌人的主搏动中获得一格电，满两格后保留电荷，远处空转不充能。充满也不会自动射向敌人，必须真正发生敌方碰撞才释放：接触目标受 6 伤害及 0.18 秒麻痹，再从该目标向周围 105 范围内传导最多两次，造成 3/2 伤害。主目标之外不重复、不跳队友、不穿墙；释放后电荷归零。近身吸附与撞角有利于触发，保持距离能阻止其继续充能和首发。眩晕与掉件清空电荷。

攻击行为由每个独立子包自己的演员处理，只有已安装的攻击件参与；掉件清除蓄能与持续攻击状态，复捡重新蓄能。激光使用暖色虚线预警与持续粗光束，电弧使用电荷提示、冷色接触爆闪与分叉传导，分别对应可横移躲开的持续直线暴露和必须碰撞的近身放电。持续 FX 用命名通道更新与取消，停止后不遗留旧射线；场景统一按世界坐标裁切和播放。

撞角与电弧首发使用各自子包注册的攻击扇环，由真正的接触攻击演员报价扣血；本体的碰撞和 FanHit 回调只处理运动、麻痹或触发后续传导，不直接扣血。电弧传导由单次独立演员结算，仍归属于泵之心。运行时来源审计与完整命中链路均有回归检查，未放宽引擎规则。

场下零件直接使用装配时的完整 SVG，包含黑铁壳体、管道、紧固件和功能结构，停放与飞散都不再使用简化图标。统一显示框为 36，场地与墙体预留半径 26，拾取接触半径 18；掉件、牵引和原地微动均遵守这个完整占地。预览页同时展示安装效果与完整散件，并校验两者的结构节点一致。

回归检查：`go test ./character/engine_heart/...` 与 `node character/engine_heart/scene_regression.cjs`。

现有协议的限制：快照只提供净 HP 变化，同一感知间隔中的治疗可能抵消掉血，不能声称能恢复每笔实扣；没有通用的引擎拦截标签或拦截回执，瞬间出生并消失且从未被感知的飞行弹也无法重建路径。夹板不使用整圈 Shell 来伪装成全向免伤。

`world.go` 保存每只泵之心的场景状态，独立场景演员即使本体眩晕仍会推进零件飞散和回收；私有状态按对局与主人隔离。零件不是可供其他角色认领的单位，除主人外不可拾取。
