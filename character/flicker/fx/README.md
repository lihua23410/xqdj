# 闪烁音效

四段原创程序合成声音，无外部采样，随本仓库采用 MIT 许可。
在仓库根执行 `python character/flicker/generate_sfx.py` 可逐字节重建。

- `reflex.wav`：0.18 秒下降电子音叠加低通噪声，表现启动和侧移。
- `shot.wav`：0.085 秒短促子弹射击。
- `overdrive.wav`：0.14 秒更低沉的完美反击末发。
- `armed.wav`：0.065 秒轻微就绪提示。

均为 48 kHz、16 位、单声道 WAV。音量由固定声音池控制，无循环；
状态快照不触发声音。通用音频管理器处理暂停、静音和导出。
