# 教父(青年)前端

完全采用抽象元素：深色圆球、金色斜切线、酒红弧形缺口、三格资源标记和定向短脉冲。没有脸、头发、身体、服饰、手枪、针筒或弹头的具象轮廓。强化只让酒红弧段、切线与移动线变亮。

## 状态与动作

- 只读取既有 `doses` / `buff` 事件、所属弹体和速度快照，不修改后端或公共前端代码。
- 针剂数量收到事件后才显示为实心；未收到时显示虚线资源格，不默认宣称还有三支。消耗时对应空槽短亮，和同拍的强化事件共用一次反馈。
- 强化只跟随现有开关。保持原有三格语义，不推算八秒倒计时；强化刷新仍有一次针剂反馈。
- 每份快照中新出现的所属子弹触发定向几何脉冲、切线内收和手枪声。普通三连与强化五连沿实际发射节奏表现，不在前端自行补发子弹或重排节奏。
- 两类弹体均用细短光划表示；强化弹的赤金颜色依据弹体自身种类显示。强化结束后，已飞出的强化弹不会变回普通弹。
- 高速移动时出现沿实际速度方向转动的短掠过线。进入高速档或高速反向时播放掠过声；它是移动装饰，不声称确认了命中、折返判定或挡伤。
- 去掉包内重复生成的残影，保留已有通用残影；不修改共享渲染器。
- 脉冲、切线内收和资源格反馈按对局时间计算，暂停后保持进度。时间回退时清理旧状态与声音；卸载某个造型节点不会抹掉其他视图使用的已确认针剂状态。

## 音效与许可

三份素材于 2026-10-30 核对为 **CC0 1.0 Universal**，允许免费商用、修改和再分发，不强制署名。完整许可在 `LICENSE-CC0-1.0.txt`，逐项核验记录在 `license/`，源文件和输出哈希、处理参数在 `audio-sources.json`。

- `pistol.wav`：DeltaCode 的 [handgun-one-shot.wav](https://freesound.org/people/DeltaCode/sounds/668348/)，作者制作的手枪单发效果。裁成 0.17 秒，压柔瞬态与高频，适应 0.12 秒的连发间隔。
- `inject.wav`：taure 的 [syringe.wav](https://freesound.org/people/taure/sounds/465495/)，针筒抽推和玻璃轻敲实录。截取 0.28 秒的短促片段。
- `rush.wav`：spycrah 的 [Knife/sword swing](https://freesound.org/people/spycrah/sounds/471097/)，取空气掠过部分，剪短、轻微加速并削减高频，作为贴身冲撞的移动提示。

使用作者公开提供的高质量 MP3 预览；处理烘焙为单声道、44.1 kHz、16-bit PCM WAV，运行时不变速、不变调、不外链播放。

播放采用现有 `arena.voice`，重触发为 `stop → reset → play`。手枪为 PREEMPT（mode 1）/ 优先级 199 / 音量 0.65；针剂为 IMMUNE / 音量 0.55；掠过为 NORMAL / 优先级 205 / 音量 0.45。各有两个实例，最小触发间隔分别为 0.075、0.3、0.12 秒。短音按真峰值控制，分别为 -5、-8、-10 dBTP。

项目文档 `docs/godfather-youth-sfx-preview.wav` 是四秒顺序试听：三连发、针剂、五连发、掠过声，使用与游戏一致的音量，并非实际对局录音。

## 验证

- 抽象几何造型、普通/强化弹区分、三连与五连节奏、针剂消耗与同拍事件去重、未知数量、强化结束、所属关系、暂停、时间回退、卸载清理和无重复残影生成检查通过。
- 浏览器核对放大造型、36 像素实战尺寸、消耗与强化回落；真实对局确认开局三支及耗尽后的空槽显示正常，无脚本或音频加载错误。
- 运行中的三个 WAV 与包内哈希一致，脚本和样式与本次版本一致；试听严格为四秒、352844 字节。
- 本轮未另行运行完整视频导出。
