# 巡航是可改的带子，速率为零不推

战斗机的巡航和视野原先出生后钉死，超速才往巡航拉，低于巡航不推。内燃机的档位需要改稳定速率和感知半径，而且全体战斗机都应能随时改这两项，不能做成档位专用。

决定：任何战斗机都可以随时改自己的巡航和视野。快于巡航拉回；慢于巡航但仍在动，沿当前方向以回拉一半往上推；速率为 0 不推。改巡航或视野不会自动改当前速度。

不采用「只改当前速度、巡航永远等于规格」：超速会被拉回出生值，低档无法成为新的稳定速率。速率为 0 时不推，是为了让站定（虚弱、居合、锁敌）继续有效，也避免零向量没有方向时沿默认轴起步。

## Considered Options

- 巡航钉在规格上，角色每帧把速度写成更快的值——和减速系统较劲，超速仍按出生巡航拉。
- 慢于巡航时也从 0 往上推——狼人锁敌、地慧星居合、内燃机虚弱都会滑走。
