# 巡航是可改的带子，站定靠 Stand 令牌

战斗机的巡航和视野原先出生后钉死，超速才往巡航拉，低于巡航不推。内燃机的档位需要改稳定速率和感知半径，而且全体战斗机都应能随时改这两项，不能做成档位专用。

决定：任何战斗机都可以随时改自己的巡航和视野。快于巡航拉回；慢于巡航但仍在动，沿当前方向以回拉一半往上推。速率为 0 且巡航大于 0 时，沿 `cruiseFS.dir` 立刻回到巡航，不走 +5/0.2s 爬升。持有 `Stand` 时，速率为 0 不推。改巡航或视野不会自动改当前速度。`M=0` 钳速度前把朝向写入 `cruiseFS.dir`，松手后才有方向可恢复。

不采用「只改当前速度、巡航永远等于规格」：超速会被拉回出生值，低档无法成为新的稳定速率。不采用全局「速率为 0 不推」：钉子松手后目标是巡航 150、当前 0，会被当成故意站住。站定（虚弱、居合、锁敌、绞刑架）显式持 `Stand`。

## Considered Options

- 巡航钉在规格上，角色每帧把速度写成更快的值——和减速系统较劲，超速仍按出生巡航拉。
- 全局速率为 0 不推——钉子这类「被按住」松手后不会恢复巡航。
- 慢于巡航时从 0 按 +5/0.2s 爬——恢复巡航会拖，方向还可能落在默认轴。
