# 挡视线是实体标签，只挡索敌，不进感知过滤

引擎的感知（`emitLocked` 按「中心距 ≤ 视野，自家白名单除外」裁 `Nearby`）从来没有视线遮挡这回事；想要"墙后藏身"时，备选是把遮挡做成世界规则（改感知过滤）。没走那条：感知管道零改动，`Seek` 旧语义不动，`VisionBlock` 做成挂在实体上的标签——单位（`Spec.VisionBlock` 出生带，`VisionBlock` 令牌运行时挂摘，谁都能给谁挂、无权限校验）和 `PlaceWall` 造的墙（`PlaceWall.VisionBlock`）声明标签，`unit.SeekLOS` 在索敌层把「球心连线被带标签实体压住」的候选跳过（墙按胶囊、单位按圆、相切算挡、敌我不分）。代价是"挡视线"不是世界规则：不查视线的索敌、碰撞、出伤、感知照旧隔墙进行，血契建线、雷达激光、老牧师全部无感。这是故意的——会不会用掩体成为球与球的差异，而不是引擎一改全场跟着变。

场地预放墙明确不带标签（`FieldWall` 没有这个字段）：场地是中立的舞台，只挡身体，永远不挡索敌。硬墙的方端不进视线判定（`WallView` 只有端点和半径，视线一律按胶囊量，方角差视为近似）。
