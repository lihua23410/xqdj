# 迷走：中点自己巡航，撞墙把整张迷径弹出去

大图（大六边形 Extent 472.5、内切 409）上，引导圆半径仍按 280 的 0.45 = 126，五条轨环圆心最远只到 126+50，加环半径 130 也只有 306，环根本碰不到场边；心环锚点又钉在近场心，于是整张迷走被锁在中心区域。

决定：把原来钉死的中点升级成迷径的平移中心（心环锚点改挂它）。中点开局从近场心的铺图点出发，方向随机、速度 150，恒速直线走；迷走撞墙时按墙法线镜像反弹，场边、硬墙、胶囊墙都算，0.5 秒冷却。中点没有碰撞体，不参与场边扫掠；它的可行域是场地轮廓内缩「引导圆半径 + 栓绳 50」，越界自己沿最近边反射并推回。心环仍相对中点做 50 的栓绳漂；轨环仍绕心环圆心转，半径和角速度规则不变。

取「撞墙反射」而不是「撞墙后朝场内走」：场边法线是 outward，直接取法线会把中点永远推回场心，覆盖更差；镜面反射保留切向分量，中点才能沿墙滑到别处。取 0.5 秒冷却，是因为迷走每拍骑轨会反复进出墙的接触区，不挡会按拍翻转。取 150 而不是 170，是让中点平移与迷走绕环错开一点相位。

代价：中点不再固定，`TestDriftStaysInLeashAndWalkable` 的「hub anchor moved」断言与 CONTEXT 心环词条要一起改；大图上的伤害覆盖会变，需要重跑胜率。
