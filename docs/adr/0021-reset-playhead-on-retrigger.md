# 重触发声音时归零播放头，而不是从尾部继续

同一个声音对象用 `stop → reset → play` 重触发时，如果 `reset` 只清“被取消”标记、不把播放头拨回开头，第二次触发就会从上一段的尾部起播。音效长度接近触发间隔时，这一次会直接落在结尾附近，听上去就是“没声”；再下一次因为已经进入 ended，反而会从头重播。

决定：声音的 `reset` 必须把播放头归零；只有命中停顿、暂停后的恢复才保留当前位置。所有重触发统一走 `stop → reset（归零）→ play`，暂停/恢复不走 `reset`。这条规则适用于默认受击/碰撞、内燃机的攻击/爆发/换挡/巡航、近战、远程、老牧师、狼人、诡术以及之后新增的声音。

代价：`reset` 不再只是清仲裁状态，也会改动媒体元素的播放位置；循环音和需要从中断处继续的声音不能调用它，必须走显式的恢复路径。这样实时对局与导出页才会从同一位置起播，不会出现“实时只丢第二发、导出从第二发开始全丢”的不一致。
