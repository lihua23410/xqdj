# 探针和场地快照归属于对局

胜率工具会并发创建多个 Match。进程级的非因果 Install/Current 和 unit.LiveField 即便加锁，也会让一场读到另一场的数据：普通局开局还能把另一场的探针清成 nil。

决定：

- 探针协议放入 internal/unit，生成结果保存在 Match.probeTape；非因果通过 SpawnInfo.Probe 接收，并深复制所有轨迹、血量和频谱切片。频谱在生成记录后计算，发布后不再修改。结束本场只释放本场记录。
- 删除 SetLiveField、LiveField 和隐式依赖当前场地的 HexContains。几何辅助函数显式接收 Field。
- Sense.Field 是本拍的场地快照。出生时由 SpawnInfo.Field 和 Context.Field 提供本场快照；演员循环每次收到 Sense 都更新自己的 Context.Field。伤害和碰墙等不带场地的事件使用该演员最近收到的快照，不查询其他场的状态。
- 弓箭将场地与安全向摘要一起缓存，供伤害事件触发的翻滚使用。

验证覆盖并发探针、普通局交错启动和重置、探针切片深复制、圆与奇美拉并行出生后首次碰墙，以及 Sense 更新后场地和动态墙信息的保留。

本次仍保留 sim 对非因果包的现有探针编排依赖；移除该依赖属于后续架构调整。人偶使的全局队列、主人表和按单位 ID 索引的状态表也不在本次两条数据链的隔离范围内，不能据此宣称整个引擎已无跨场共享状态。
