# 非因果演出作为独立录像段导出

直播在探针演出期间暂停真局，只广播而不记录比赛帧；完成演出的回执会清掉快照中的 intro。因此导出结束后的比赛帧不能还原开场倒带。

决定：开局归档一份 introFilm 和推进前的真局初态，与比赛帧原子取得并交给导出任务。演出轨迹只存一次，不在每张比赛快照里重复记录。直播回执、停场和下一局都不能改写已交给导出的记录。

导出顺序为片头、可选探针演出、首帧停留、正式比赛、胜者定格。服务端通过任务元数据下发各段帧数、帧率和总帧数；演出长度为向上取整的 `(1 + death/10) * fps`，不包含等待回执的超时余量。没有有效演出时新增段为零帧，沿用普通局时间线。

正常观战和导出复用 drawIntro。直播使用接收后的经过时间，导出使用段内帧号。演出期间冻结比赛假时钟，并禁用音轨事件记录；离开演出时清除演出层、相关 GSAP 动画及该段创建的定时器和 RAF。比赛音效按最终视频中的绝对帧号记账，首拍只播一次。

新增比赛特效会创建合成层，首次正式比赛画面需跨过一次实际绘制再截图，避免捕获未完成绘制的黑帧。

验证包含录像生命周期、带/不带演出的帧数、元数据与比赛帧分离，以及显式开启的真实浏览器/编码测试：普通局、非因果单挑、非因果团队赛。浏览器测试检查倒带位置、比赛时钟冻结、演出层清理、首拍音效和视频帧数，并保存关键帧截图供人工检查。
