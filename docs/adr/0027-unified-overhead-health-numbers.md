# 场内生命统一显示为头顶数字

场内原先混用角色私有血条、私有数字和公共数字，一些活随从没有读数，非因果影借用皮肤时还可能重复绘制。决定由公共显示统一维护白色当前生命整数的样式、取整与定位，覆盖可见战斗机和全部活随从；私产删除重复绘制，特殊角色只决定生命来源并复用公共绘制入口，以避免之后再次分裂成多套显示。

保留游戏页面与导出视频的场外血条。场内数字四舍五入，生命大于 0 时最低显示 1；隐藏本体和明确隐藏数字的演出继续隐藏，普通子弹、分身与辅助物不因此增加生命数字。红蓝半按真实主人取生命，不能取同边第一个战斗机，也不能在主人缺失时退回显示其自身占位生命；非因果三类影继续显示影自己的生命，不跟借用皮肤改变来源。伤害／治疗飘字、状态角标和靶子的伤害播报不属于本次统一。
