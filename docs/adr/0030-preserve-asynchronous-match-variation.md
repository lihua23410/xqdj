# 保留异步行动造成的对局差异

相同场地、人选和随机种子下，异步行动仍可使局面和胜负不同。这是游戏明确保留的特性，不作为种子失效或统计工具不可靠的证据；增加并发数后出现单场差异，也不能单独据此判错。

胜率工具和 GPU 加速继续保留完整战斗规则及异步行动特征，不以消除单场差异为目标，也不要求 CPU/GPU 同种子逐场对齐。计算模块可用相同输入核对数值和规则；整体统计结合样本量与重复试验评估，不能用单场结果完全相同代替验证。

跨场共享主人表、出生参数或协作标记造成的污染仍是隔离缺陷，由 ADR 0029 处理。修复跨场污染与保留异步差异是两项独立要求。

允许异步行动先后差异，不授权丢失伤害、碰撞或生命周期等规则事件，也不授权角色持续读取积压数秒的旧感知。2026-11-02 的诊断已确认，旧收件箱满时会静默丢弃 IncomingDamage，造成随并发条件变化的系统性漏扣血；这是消息投递缺陷，不能用本条作为合理化理由。

可靠投递与阶段背压的修复口径见 [ADR 0031](0031-reliable-actor-events-and-batch-backpressure.md)。
