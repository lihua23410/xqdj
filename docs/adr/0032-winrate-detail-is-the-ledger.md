# 胜率明细是账本

`-only` 要把一只战斗机的新对阵写回已有全表。矩阵百分比只保留一位小数，对不回原始胜负平。旁边再放一份 json，两份成绩就会各写各的。

决定：`winrate.md` 的一对一明细就是账本。增量运行只替换涉及该战斗机的对阵，再整篇重算单球胜率、两张矩阵和明细。`-n` 和 `-timeout` 必须与报告头一致。当前名册里除这只以外的每一对必须已经在账上，写回后每一对都要在。对不上就退出，不改原文件。不带 `-only` 的全量运行仍整份覆盖。靶子不在这本名册里；明细里已有的靶子对阵写回时丢掉，不要求补齐。

不另建机器可读账本，也不按矩阵格子改数。明细列保持不变，所以已有报告还能接着合并。
