# 接触攻击归独立扇环，严禁战斗机本体碰撞出伤

本体全圆碰撞会让身后的目标受伤，也让伤害范围、画面朝向与扇环专项减伤各说各话。决定：严厉禁止在战斗机本体的 Collision、FanHit 回调及其辅助函数中出伤；接触攻击必须归独立 Attach 扇环，由扇环自己的 ID 报价。不得通过辅助函数、伪造来源或跨事件延迟扣血绕行。本体保留原有身体碰撞规则与必要的状态变化；范围伤害、持续伤害、自扣血是独立机制，不按伤害 From 是否为本体一刀切禁止。

张角按战斗机与招式分别确定：pink 平淡 180°、油箱电锯 144°；盾斧两种突刺 120°，附带群伤同样只打前方；回声 90°；钓鱼佬高速状态 180°；血契饿扑 110°，保留独立于普通咬合的一次伤害；青年撞击和折返均 90°，返程随实际速度反向；我与周旋久双方各 180°，互撞掷状态与扣血拆开；人偶使围身冲刺 120°，结清命中当下尚未消耗的段数。伤害数值、攻击次数与原有动作联动分别保留，外观沿各自私产风格。

采用本场 MatchState 内同步的攻击窗口。扇环报价后由引擎通知主人 FanHit，主人只处理眩晕、折返、接招、建线等后续动作，避免本体重复报价。一次冲刺只挂一道，普通接触按原冷却重挂，多目标电锯每目标只结算一组三段；窗口结束清掉余弧。指定目标及多目标窗口采用已有 Pass 规则，普通弧沿已有 Attach 接触结算；搭档互伤显式允许同边和主人接触，其他扇环过滤规则保留。物理扫掠前同步主人当下的位置和速度，避免起步或折返时扇环沿用上一拍方向。扇环伤害自然进入已有的扇环专项减伤，击杀仍按主人归功；引擎报价携带实际来源的 OwnerID，保证 pink 的新生扇环在首次感知前也能正确伤到自己的人群。

独立 internal/audit 包负责两层检查。静态层在 make audit / build / run / test 及仓库边界测试中扫描已注册战斗机的本体碰撞分支，追踪本包命名辅助函数及同接收者方法；发现 Damage 或无法识别的注册规格、战斗机工厂则失败，命令入口 panic 并报告位置与调用链。README 的最小骨架同步改为扇环，不能再教维护者写本体碰撞出伤。

运行时层放在引擎结算入口。演员拥有私有输出通道，事件起止标记与命令共用 FIFO，转发时附上引擎记录的真实单位与事件来源；事件结束确认必须等命令转发完成，沿用已有阶段背压及演员异步先后差异。战斗机处理本体 Collision 或扇环 FanHit 通知时发出的 Damage，无论自称 From 是什么都立即 panic；真实扇环的报价与命中通知必须 From 自己，命中通知同样核验真实发送者。额外的转发协程和起止确认有成本，换来不依赖角色自报来源的检查；不将角色回调中的 recover 当作防线，因为硬断言在引擎协程执行。

裸 go build 不执行自定义静态审查，但编译后的程序仍有运行时硬检查。静态层不完整证明接口分派、函数变量、跨包调用、跨事件状态流，运行时只在违规路径执行时触发；有源码或发布权限的人仍可删除检查，不能声称防止恶意维护者或阻止文件上传。受保护 CI 是发布侧的额外措施，本次不虚构仓库尚未配置的发布门禁。这里记录的是防回归的强约束，不是恶意 Go 代码沙箱。
