# 连续油面与按时间推进的火头

2026-11-03，已采纳。

纵火者原来用大量重叠圆盘表示油滩与拖尾，每拍逐圆发送特效、逐圆维护 DOM，并全盘重算蔓延。重叠圆的接缝和光晕让观众难以分辨真实火头，开销随历史铺油次数增长。油火 FX 还会落入通用一次性特效流程：没有动画结束事件的空节点一直累积，2000 条 FX 连续 30 拍能留下 60000 个空节点。

决定重写油面状态、蔓延和绘制。后续美术与数值调整：蔓延速度改为 80，被点燃的油燃烧 2 秒，火瓶空地火与敌人离火续烧各保持 1 秒；投瓶、拖尾、冷却和伤害节拍保留。补充领域规则：**同一只纵火者铺出的油，只要实际相接就连通**，不再按瓶次、拖尾段或铺油时间设隔离。瞬移空档仍不铺；落地油若接到已有油就合并。不同纵火者继续隔离，见 [ADR 0034](0034-fire-burns-own-oil.md)。

## 状态与蔓延

每只纵火者的油火随从持有自己的稀疏网格，每格宽 3 世界单位，按 32×32 分块。油瓶以半径 54 圆的面积为基准，写入稳定的不规则泼溅轮廓，混合不对称圆润油舌与少量飞溅小滴；主滩与小滴合计面积归一，控制形状变化的面积偏移。每瓶采用独立种子，轮廓写入覆盖后不随时间随机抖动。油瓶在飞行途中按已走过的路程写入参考半径 8、略有偏摆与宽窄变化的细油带，并间隔留下少量小滴，落点的主油滩盖住带子末端，不留断口。实际移动的拖尾写成略有边缘起伏、偏摆与宽窄变化的连续油带：贴着油滩的一头是 1.9 倍身体半径，沿 90 长度收回到身体半径。等粗的细管和圆盘几乎外切，接缝处会塌成细腰，两侧还各留一个凹角；锥形过渡把这个缺口填平，油面才看着是连着的一摊。两种油带的变化由已走行程和本段种子决定，每 3 世界单位采样一次并合入同一覆盖；切成不同感知帧仍得到同一条路径，避免按帧重启花纹、出现串珠。重叠油格合并，静止或重复铺相同油不增长状态。瞬移不连空档，也不消耗尚未走完的 90 长度。极小单位的拖尾按网格能连续覆盖的最小宽度写入，避免细于网格后整段漏油。

火从重合处起，按最早抵达时间推进。事件队列只处理到期的点燃和熄灭，不每拍重跑全场寻路。相邻格的时间间隔用实际格心距离除以 80；增加带中间覆盖检查的斜向边来减少方向偏差，不能跨干格。多处点火取最早抵达，不叠加速度。被点燃的油格独立燃烧 2 秒，火瓶落在空地的格燃烧 1 秒，之后移除；火瓶直接覆盖油也按 2 秒，重复投火不得缩短已有火的剩余寿命。新油碰活火会重新点燃，从这一拍重新计寿命。事件带版本，旧点燃、旧熄灭事件不能复活或提前熄灭后来补上的油火。时间跳过多拍仍按事件原定时间处理。

这是对圆与胶囊边界的离散近似，不宣称保留旧圆盘的精确边界：格宽 3，曲线轮廓和传火路径存在网格误差。命中检测与绘制共用同一覆盖，身体圆与油火格相切也算接触。油和火只决定拖尾与燃烧，不改身体碰撞。燃烧仍由油火随从向可打的敌人发送，每 0.2 秒 1 点、离开后续烧 1 秒、刷新不重置节拍、不停帧，归属与死亡清理保留。

## 传输与画面

`unit.FX` 增加可省略的 `Data json.RawMessage`，由包写入不可变的视觉载荷，引擎不解析油火几何。每次感知发送一条 `arson-surface`，携带完整当前油火状态；未变分块复用游程编码，整个状态未变时复用 JSON 字节。它是完整状态而非增量，客户端无需先看过第一瓶油；暂停沿用已有状态，回放携带相同数据。外发后不再改旧字节，避免后来烧油改变已经记录的帧。

身上燃烧另以一条 `arson-burning` 携带按 ID 排序的目标与结束时间，空列表显式清掉旧状态，不按伤害跳字推测谁还着火。没有燃烧时复用空数据，不重新编码油面。击杀、离火续烧和来源隔离仍由 Go 判定。

前端每只纵火者保留一张缓存地面 Canvas。焦油用近黑厚边和弯曲冷光高光表现黏稠；火面作为炭红底床，只有接着未燃油的火边亮起。活火另以一张 Canvas 批画最多 72 簇双层贝塞尔火舌与少量火星，不逐簇建 DOM。烧尽的格透明，火舌只从真实火格生出。身上火焰用常驻 guide 跟着目标走，多个来源共用目标 ID 对应的一张 Canvas；到期、单位消失或来源消失时由 guide 生命周期清理，血量标签保持在火焰之上。

火舌、火星、瓶口火和本体余烬的动画时相按模拟时间以 20Hz 采样，油火覆盖变化时同步重绘，没有独立计时器或动画循环。暂停冻结，回拨失效缓存，缩放与移动只调整布局。地面修订不变时不重新栅格化。瓶子用包内 CSS 画透明瓶颈、玻璃边缘与高光、瓶内液体和燃烧布芯，本体为有余烬裂口的焦黑壳。

常驻 FX 注册空的 shot 处理器，避免进入通用瞬时特效的节点创建流程。旧 `arson-oil`、`arson-fire` 名也被消费，防止空节点泄漏。整个表现复用现有 look/guide 接口，没有添加纵火者专用引擎或页面分支。

音效通过包内 `audio.js` 接入既有 `arena.voice`。碎瓶只在真正碎裂时发出一次事件，暂停重复快照按瓶 ID 去重。火声由实际地面/身上火状态触发，全包共用一秒限频、固定声音池，交替短片段，不按火格数叠加，也不启动会遗留的永久循环。原创玻璃/液体合成与仓库 CC0 火焰录音混合，来源、许可、重建脚本与测量见包内音效说明。

## 验证

Go 回归覆盖 64 种泼溅种子的面积、范围、轮廓差异与稳定性，油带分帧一致、细油线连通与宽度范围，以及连续拖尾、冷却、瞬移空档、不同铺油相接、断油不跳火、不同主人隔离、80 速度、点燃油 2 秒/空地火 1 秒、补油、旧事件失效、大时间步、燃烧节拍、死亡、不可变完整数据与判定/画面覆盖一致。引擎集成测试验证油火数据进入真实观众快照，暂停保留，录像不丢。Node 回归执行真实 `app.js` 特效入口，验证不产生空节点、单图层、静止复用、缩放、回拨与火边颜色，以及火舌数量上限、模拟暂停、身上火焰寿命、多来源共用和玻璃瓶只挂载一次。

本机微基准，非整场帧率承诺：2000 次重叠半径 18 圆的铺油足迹，原先静止感知约 1.58 ms、2001 次分配/拍；新实现缓存覆盖和空燃烧列表，使用两批 FX，同一静止足迹约 0.00021 ms、2 次分配/拍，避免历史圆盘数导致的全盘计算。燃烧基准只测油面推进和编码，不包含浏览器与伤害结算。浏览器压力复现中，2000 个常驻油面图层降为 1 个；地面有火时增加一张共用火舌 Canvas，每个燃烧目标再增加至多一张共用 Canvas。动态火面加一个燃烧目标的 30 帧局部验证，平均约 0.69 ms/帧，空特效节点为 0；活跃面积、单位数、视口与机器会影响整场结果。
