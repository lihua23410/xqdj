# 教父前端改造

## 已确认的方向

- 气质：沿用黑金与暗色系，以抽象几何和动作节奏表现身份。
- 形态：保留圆球；只使用切线、弧段、缺口、刻线和散点。教父和三种活随从不画脸、身体、服饰、刀枪或提箱。
- 范围：教父本体、暗杀者、狙击者和贩卖者，形成统一的家族形象。
- 视觉关系：教父用双弧与叠切线；暗杀者用斜切线；狙击者用错位刻线；贩卖者用阶梯折线。通过配色与动作区分分工。
- 信息密度：以职业识别和动作反馈为主，保留现有生命数字。
- 动作风格：暗杀者用赤色掠过线；狙击者用定向几何脉冲与边沿刻线内收；贩卖者用短环和散点；补员时教父的叠切线短亮。
- 弹体造型：按用户要求保留原有铜被甲穿甲弹，本次不调整。
- 药物造型：按用户要求保留原有白色粉末堆，本次不调整。

## 改动边界

- 代码改动仅限 `character/godfather/fx/`；后端逻辑和角色包外的代码均不修改。角色包外仅更新文档。
- 读取现有快照、瞄准与退场事件，不增加后端状态或事件，不修改碰撞范围、出伤、回复和补员规则。
- 开火、投放与补员的装饰反馈依据连续快照中新出现的对应单位。中途加入时不会把已在场的子弹或药物当作新动作重播。
- 动作的后坐、粉尘和徽记亮度随对局时间计算，暂停时保持当前进度。
- 保留现有拾取后的通用回复数字，不依靠药物消失去推测拾取者。
- 音效同样只在教父包内接入：以皮鞋、短刀、单发步枪、箱扣与纸袋实录表现家族特征，采用已核对的 CC0 素材。音效来源、许可和触发规则见 `character/godfather/fx/README.md`。

## 验证

- JavaScript 语法与差异格式检查通过。
- 粉末与狙击弹的 SVG、尺寸、样式和钩子代码与改造前逐块比对一致。
- 包内钩子的造型挂载、清理、所属关系、垂直瞄准、进攻与退场区分、开火和投放反馈、暂停及时间回退检查。
- 浏览器中检查实际对局、放大造型与实战尺寸；药物同时检查放大颗粒和实际尺寸下的粉末轮廓。

## 设计依据

教父自身不直接出伤，战斗围绕活随从组织。以球体大小、色调与不同几何纹样体现教父和三种活随从的关系，和青年版保持一致的抽象风格。保留已有双线收束瞄准、投放、补员与退场的反馈。

抽象造型对照图见 `godfather-abstract-preview.jpg`，实际对局图见 `godfather-frontend-battle.jpg`。

沿用项目中的“教父”“活随从”“暗杀者”“狙击者”“贩卖者”“药物”和“退场”等既有术语。药物仍为白色粉末聚集物；活随从用尽次数后退场，与生命归零时消失是两种不同的表现。
