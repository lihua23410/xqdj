# 教父(青年)前端改造

保留小球的抽象风格，以深色圆球、金色斜切线、酒红弧形缺口和三格资源标记表达青年教父。所有特征通过颜色、几何和动作节奏呈现。

## 视觉约束

只使用圆球、线段、缺口、色块、资源格与短脉冲。禁止画脸、头发、身体、服饰，以及手枪、针筒、弹头等具象轮廓。此约束覆盖下面所有状态与动作。

## 已确认的方向

- 发射时出现短促的定向几何脉冲，边沿切线轻微内收，按实际弹体的三连/五连节奏呈现。
- 普通弹与强化弹均表现为细短光划，分别使用暗金与赤金颜色；颜色跟随弹体自身种类。
- 三格矩形资源标记固定排列，表示针剂余量；消耗后留下空格，消耗瞬间短亮。
- 强化让酒红弧段和金色切线变亮；高速移动用短掠过线，随真实速度方向转向。
- 清理重复残影生成，减少画面堆叠。
- 手枪声轻短，针剂声干脆，撞击阶段用短促空气掠过声。

## 改动边界

代码与素材均位于 `character/godfather_youth/fx/`，外部只更新文档。后端、公共前端和其他角色包代码不变。

所有表现依靠现有针剂/强化事件、单位速度和两类子弹，不新增战斗事件，不修改出伤、回复、针剂次数、三连/五连规则、强化持续时间、碰撞或挡伤。

针剂未收到状态时显示虚线资源格；不猜剩余数量。强化只跟随已有开关，不增加倒计时。移动装饰不充当命中或挡伤的精确提示。
