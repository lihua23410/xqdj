# 观察者对局视觉

## 生物独眼

- 保留浅青灰主体与视线的浅青亮芯。灰白湿润眼睑、少量暗紫血管和不对称的眼褶包住竖瞳独眼，不增加机械镜头、攻击范围圈或额外触手。
- 瞳孔跟随实际观察目标，失去目标后轻微游移。眨眼、虹膜呼吸、记录亮边与发射收缩按对局时间绘制，暂停与停帧时保持原姿态。
- 视线弹沿实际速度方向绘制；敌方弹体复现保留原形状，涂色和公共拖尾仍使用观察者主体色。视线保留自己的浅青亮芯。

## 观测与胶片

- 观测条固定单行标题和百分比，使用后端已按上限 75 归一化的数据。
- 左侧三张弹体胶片各对应一个种类，色相按记录槽写入；这一轮消耗后清空，下一轮不会继承已丢弃槽的颜色。新种类记录时有一枚小胶片从记录位置收向主人，并使相应槽短亮。
- 右侧特殊胶片显示已真正归档的弹体总发数，包含视线；普通弹也计入。叠片层数按总发数显示，最多三层。视线数单独用于亮边与悬停说明，没有视线不影响总数。没有数据的旧录像不猜测数量，已确认空胶片才显示零。
- 复现期间显示尚未打出的发数，按实际队列结束；不再用固定 1.3 秒的亮起时间代表整轮发射。
- 锁定与命中只留局部短效，取消大范围爆闪。主人每次最多保留 24 个短效，短效和状态随主人节点清理；重新开局或对局时间回退时重新建立。

## 数据与实现

私有资源位于 `character/observer/fx/`。Go 只补充一条观众事件 `observer-film-state`：`Amount` 是已归档视线数，`VX` 是已归档总发数，`VY` 是待发发数。已归档包括上一轮胶片和这一轮已经飞出去的部分，不把尚未发射的视线提前计入。

该事件和现有 `observer-state` 同步发送，不进入战斗规则。前端私有状态寄存在 `observer-state-<主人 ID>` 节点，沿用公共引导层的生命周期；不修改公共网页、选人界面、伤害、观测节奏、记录规则或胶片保留规则。
