# 普通雷达视觉优化

状态：已完成并通过浏览器验证。

## 已确认

- 只借鉴雷达(百战)的精细质感，不添加球外十字、同心圆或其他球外标线。
- 保留普通雷达现有绿色：主体 #3eb87a，深部 #1f4d3a，荧光 #7dffb3、#5cff9f，激光亮芯 #b8ffd9。
- 球体内部少量结合玻璃管、细栅格、绿色荧光片与扫描纹理，整体克制。
- 激光采用清晰亮芯和墙截断端的小亮点。
- 选人界面保持原样。

## 具体表现

- 保留圆球轮廓，球面呈深绿玻璃质感，内部加低亮栅格和小面积荧光片，边缘一小段柔和反光。
- 扫描纹理只在球体内部淡淡可见，荧光有极轻微起伏；不做随机闪烁或强烈故障效果。
- 激光仍是一条从球心发出的细线，用清晰的浅绿亮芯和收敛的绿色光晕表现；墙截断处是一点局部绿光。
- 激光朝向与长度完全跟随现有战斗数据，实际长度为 0 就不虚画线段或端点。装饰动效随对局时间，暂停与停帧时停住。
- 同步普通雷达的名册说明和外观插图。

## 实现边界

- 只调整普通雷达的私有前端资源与相关说明、插图。
- 不修改雷达(百战)、公共引擎、选人界面和整页布局。
- 不修改伤害、判定宽度、旋转节拍、墙截断或眩晕规则。
- 不加入炮塔、点名、锁定圈、炮击或额外音效。
- 保留「激光」与百战「扫掠线」的区别，球内纹理不代表攻击范围。

## 验证方向

- 检查正常球体、激光长短与方向、贴墙或长度为 0 的显示。
- 检查暂停、眩晕、单位移除、对局重置、同场多只雷达及导出显示。
- 确认选人按钮、百战资源和战斗逻辑无变化。

已通过：普通雷达与雷达(百战)的 Go 测试、现有前端 7 项检查，以及雷达浏览器验证。浏览器覆盖原色保留、无球外标线、墙端亮点、0 与 0.25 的真实激光长度、暂停、无新激光事件时沿用旧状态、多人隔离、移除与时间归零清理、百战隔离、单挑/团队赛纯文字选人，以及普通观战和导出。
