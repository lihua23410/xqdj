# 筑墙者视觉优化

状态：已完成并验证，采用用户指定的现有土黄色主题色。

## 已确认的范围

- 只优化普通筑墙者，采用现有土黄色主题的几何构筑风，主题色为 #c4a36a。
- 可以调整对局中的球体、瞄准虚线和施放反馈，同步名册插图。
- 选人界面保持原样，不添加小球图标或预览。
- 实际墙的外观、生成与消失效果、几何、碰撞、伤害、寿命、生成节拍和落点全部保持原样。
- 筑墙者(百战)、其他战斗机和整页布局不在范围内。

## 具体表现

- 球体保留圆形轮廓，以原主题色的明暗层次、细边和分层几何刻线表现构筑感；少量几何线缓慢转动。
- 瞄准虚线保留准确的位置与长度，使用主题色分段线和两端短刻度；平时低亮，施放瞬间短亮。
- 实际砌墙时，球体上的几何线短暂收拢、亮起，然后向球外散出少量同色小方片；约 0.3 秒收束，不在墙身加效果。
- 所有反馈保持局部、短促；不加全屏闪光、镜头震动、额外声音或技能倒计时条。
- 暂停与停帧时动效停住；眩晕或没有可用目标而未实际砌墙时，不播放施放反馈。新对局重新开始，球消失时清理私有表现。

## 实现约束

- 新皮肤与脚本放在普通筑墙者的私有资源包内。
- 保留 Look.Color 的原始值，因为公共墙绘制直接用它决定墙色；新球体配色只在私有皮肤里调整。
- 施放反馈使用普通筑墙者实际发出 PlaceWall 时附带的私有观众态事件，明确标识施放者，支持多只同场。
- 复用现有瞄准几何和皮肤钩子，不改墙绘制与公共样式。

## 验证

- 检查球体、施放瞬间，以及单挑和团队赛中的显示；选人按钮保持原来的纯文字。
- 检查暂停、重新开局、施放者消失与同场多只筑墙者，确认不误触发或残留。
- 运行相应 Go 和前端检查，核对墙参数与百战代码无变化。
