# 盾士视觉优化

状态：已完成并验证。

## 已确认的方向

- 灰蓝重甲本体与贴身拼接盾环，碎片用 #8b9cb3。
- 破盾冲击感偏强：近身冷白短闪、盾环崩裂、短促的断续扩散弧；不加镜头震动或额外停帧。破盾有一段短促金属碎裂音，mode 2（IMMUNE）。
- 真实碎片呈较厚的金属甲片，按实际飞行方向绘制，带极短拖影。旧盾还在时不换、不飞碎片。

## 具体表现

- 本体保留圆球轮廓，增加灰蓝金属明暗、护甲接缝与少量冷白边缘高光，外观不依赖盾环才能辨认。
- 有盾时，贴身整圈盾环清楚可见，接缝只表示拼板造型，不表示剩余耐久；无盾时，盾环完整消失，露出本体。
- 新盾实际出现时立即显示完整防护轮廓，再以短促的拼片归位、高光合拢表现补盾，不先隐藏有效的盾。
- 挡伤破盾时短闪、崩裂与断续短弧快速爆发，随后立即收束；装饰碎屑比真实出伤甲片更细、更淡。
- 真实碎片保留原位置、大小、飞行方向与弹墙行为，外观是不规则金属甲片；拖影短、淡，不连成整条粗光带。
- 装饰动效按对局时间走，暂停与停帧时停住。
- 破盾使用约 0.28 秒的金属碎裂声，mode 2、priority 0、volume 1.0。同一盾士的同一次碎盾在暂停重复渲染时不重播，不同盾士独立播放；导出使用相同入口。

## 边界

- 只改盾士包的私有前端资源、外观登记、必要的纯展示归属信息，以及说明与名册插图。
- 可以给现有破盾展示事件补施放者 ID，以便同场多只盾士各自联动；不改变触发时机或战斗指令。
- 选人界面、公共引擎、其他战斗机不在范围内。
- 不改变挡伤、补盾、伤害、碎片数量、速度、半径或弹墙规则。
- 不加入盾耐久条、补盾倒计时、提前补盾预告或无法确认归因的命中特效。

## 验证

- 有盾、无盾、新盾装上。盾还在时到点不换。
- 破盾碎片与装饰碎屑的区分。
- 多只盾士、暂停、眩晕、退场、重置及普通观战/导出。
- 选人纯文字按钮、战斗规则和公共引擎保持原样。
