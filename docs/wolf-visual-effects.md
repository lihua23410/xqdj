# 狼人对局视觉

状态：已实现，经过浏览器与战斗回归验证。

## 本体与月亮

- 保留骨白本体、浅金月亮，以及撕咬时的淡红色系。
- 本体保持骨白圆球与立体球面，上沿长出尖耳、外轮廓伸出鬃毛，前侧附着一对獠牙。球内不绘制完整狼头、五官或徽章，也不加框圈；獠牙朝向跟随真实扇环。
- 月面增加淡淡的月海与陨坑，八种月相使用球面投影的明暗分界；新月仍能辨认边缘，满月有轻微的暖金起伏。
- 月相变化在月亮自身边缘短亮，不再在场心额外画圈。同场多只狼人按主人独立显示月相与撕咬状态。

## 爪击与撕咬

- 平时扇环为三道不同亮度、两端收尖的骨白爪痕。
- 撕咬时球面与毛边略泛红、鬃毛立起，前侧上下獠牙更明显；真实新撕咬弧出现时，附着獠牙张开再收咬，周围使用收敛的红光，避免淹没牙齿轮廓。
- 撕咬扇环改为淡红齿弧，六枚骨白獠牙朝内，其中一对犬齿更长；真实新弧出现时短促收咬、亮边。
- 爪痕、齿列都裁在快照给出的扇环内，沿用真实的半径、内径、张角和朝向。装饰不扩大出伤范围，也不表示额外命中。
- 新增的月亮、球体附着元素和扇环动效都使用对局时间，暂停和停帧时保持同一姿态。

## 修改范围

- 私有前端资源位于 `character/wolf/fx/`，球面使用 CSS 材质，尖耳、鬃毛、獠牙与扇环为代码绘制的 SVG。
- Go 仅给两种扇环登记 `wolf-arc` 皮肤，并为原有 `phase` 展示事件补 `UnitID`；触发条件、战斗指令、伤害、时间与判定不变。
- 月相展示状态放在跟随主人生命周期的私有节点中，主人移除或时间回退后清理。旧录像若缺少月相归属，只在该阵营唯一狼人时兼容；旧数据无法区分的同阵营多狼人不互相套用月相。
- 原有变身插画、狼嚎音频及 mode 2 播放配置保留。选人界面、公共网页与引擎保持原样。
- 名册文字及狼人的外观插图同步更新。

## 验证

通过狼人包测试、扇环来源集成测试和现有前端 7 项检查。浏览器验证覆盖八种月相、同阵营双狼人状态隔离、普通爪痕与撕咬齿列、真实扇环几何与朝向、暂停、撕咬结束、移除和时间归零清理，以及普通观战、导出、单挑与团队赛选人。
